# Algebra RAG Agent

**[Отчёт по заданию](HOMEWORK.md)**

Агент LangChain читает разрешённую учебную HTML-страницу, сохраняет
эмбеддинги её фрагментов в Pinecone и отвечает с указанием источника.
Отдельный инструмент выполняет настоящий GET к `https://catfact.ninja/fact`.

## Запуск

Python 3.11+. Создать отдельное окружение и установить зависимости:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
```

Скопировать `.env.example` в `.env`, заполнить настройки модели и Pinecone.
Нужен существующий dense-индекс размерности 1024 с метрикой cosine.
Namespace `vpg04-web` отделён от набора второго задания. Ключи не публикуются.

```bash
python -m unittest -v
python rag.py
```

Запуск `rag.py` выполняет реальные запросы, расходующие квоты сервисов:
проверка Pinecone → загрузка страницы → RAG-ответ → GET к открытому API.
Результат сохраняется в `results/demo.json`. Тексты извлечённых фрагментов
не включаются в этот файл, остаются только ID, score, URL и короткие ответы.

## Инструменты

- `add_learning_url(url)` — HTML → очищенный текст → чанки 900 символов
  с перекрытием 120 → multilingual-e5-large (passage) → Pinecone.
- `search_knowledge(question, source_url)` — эмбеддинг запроса (query),
  top-3 фрагмента, источники и ответ по найденным данным.
- `get_cat_fact()` — GET, проверка HTTP, JSON и непустого поля fact;
  полученное утверждение явно приписывается внешнему сервису.

Демо-источник: https://www.mathsisfun.com/algebra/linear-equations.html
Его полный текст не распространяется в репозитории. Парсер удаляет
навигацию и служебные элементы, но не распознаёт формулы на изображениях
и не гарантирует сохранение математической вёрстки. Это HTML-пример,
а не обработчик полноценных учебников.

## Хранение и ограничения

Для страницы формируются ID с хешем URL и содержимого. Повторная загрузка
одинакового текста обновляет те же ID. Карта активных версий сохраняется
локально в `data/sources.json`. Поиск фильтрует только эти версии; более
старые записи автоматически не удаляются. В новой копии проекта нужно
заново выполнить загрузку URL, чтобы сформировать локальную карту источников.

Индекс и данные предыдущих заданий не удаляются. Чтение конкретных ID
подтверждает видимость записанных фрагментов. Готовность поисковой выдачи
в распределённой базе может отставать от записи; пустая выдача требует
повторной проверки, а не выдуманного ответа.

Для учебного прототипа разрешены только HTTPS-страницы MathsIsFun.
Расширение списка — явная настройка в `web_data.py`. Перенаправления
проверяются, локальные адреса не допускаются, тело ответа ограничено 2 МБ.
Pinecone-клиент не следует перенаправлениям с ключом авторизации.

Модель получает извлечённый текст как данные, а не как инструкции.
Промпт задаёт правила работы с источниками; он не является доказательством
отсутствия галлюцинаций во всех запросах. Результат открытого API также
не становится проверенным учебным фактом автоматически.

Память агента — InMemorySaver, только до завершения процесса. Документы
остаются в Pinecone. Работающий Telegram-бот этим примером не меняется.

## Проверки

Семь автоматических тестов: границы URL, перекрытие чанков, очистка HTML,
валидация ответа GET, отсутствие выдуманной выдачи для пустого источника,
таймаут и фильтрация активной версии. Реально проверены три инструмента
на модели gpt-6-luna, 5 фрагментов в Pinecone и ответ со ссылкой на источник.

Документация: https://docs.langchain.com/oss/python/langchain/tools
и https://docs.pinecone.io/reference/api/2025-10/data-plane/query
