# Отчёт по заданию VPg04 — интеграция памяти с API

## Задание

Подключить RAG-агента к Pinecone и проверить запрос. Реализовать загрузку
страницы по URL, разбиение текста на чанки, получение эмбеддингов и запись
в векторную базу. Заменить заглушку инструмента реальным GET-запросом
к открытому API с обработкой ответа.

## Реализация

Использованы LangChain, модель gpt-6-luna, HTML-парсер BeautifulSoup,
Pinecone и embedding-модель multilingual-e5-large. Существующий индекс
algebra-tutor-search проверен на размерность 1024 и метрику cosine.
Материалы страницы записываются отдельно, в namespace vpg04-web.

Созданы три инструмента: загрузка URL, поиск по загруженным данным
и получение сведений из открытого API. Модель выбирает нужный инструмент,
получает его результат и формирует ответ.

## Проверка подключения

Создан вектор тестового вопроса из 1024 чисел. Pinecone успешно выполнил
векторный запрос к namespace. Наличие ответа сервиса подтвердило
корректность подключения; текстовая генерация для этой проверки не требовалась.

## Загрузка учебной страницы

По запросу агент вызвал add_learning_url для страницы
[Linear Equations](https://www.mathsisfun.com/algebra/linear-equations.html).
HTML очищен от скриптов, стилей и служебных блоков. Получено
**3346 символов**, сформировано **5 фрагментов** по 900 символов
с перекрытием 120. Каждый преобразован в вектор размерности 1024.

В метаданные сохранены текст, URL, название страницы, номер фрагмента,
версия источника и embedding-модель. Чтение записей по ID подтвердило,
что все пять фрагментов доступны в Pinecone.

## Ответ по сохранённому материалу

Вопрос: «По загруженной странице объясни, какой график у линейного
уравнения и чему равны наклон и пересечение с осью y в примере
 y = 2x + 1. Укажи источник».

Агент вызвал search_knowledge. Pinecone вернул три фрагмента:

| ID | Cosine score |
|---|---:|
| `web-7280fa3748217116019e-002` | 0.8718 |
| `web-7280fa3748217116019e-001` | 0.8583 |
| `web-7280fa3748217116019e-000` | 0.8509 |

Ответ по найденному материалу: график — прямая линия; наклон равен 2,
пересечение с осью y — 1, точка (0, 1). В ответе указаны URL страницы
и ID использованных фрагментов. Вопрос был задан по-русски,
а исходный материал — на английском.

## Реальный GET-запрос

На запрос о кошках агент вызвал get_cat_fact. Инструмент выполнил
`GET https://catfact.ninja/fact`, получил HTTP 200, проверил JSON
и наличие непустого поля fact.

Полученный текст:

> The life expectancy of cats has nearly doubled over the last fifty years.

Агент перевёл его и начал ответ словами «По данным внешнего API».
Утверждение помечено как unverified_external_claim: технически успешный
GET не подтверждает достоверность содержания внешнего сервиса.

## Проверки

Пройдено **7 автоматических тестов**: допустимые URL и запрет посторонних
адресов, полнота разбиения с перекрытием, очистка HTML, обработка неверного
JSON и пустого факта, пустой источник, сетевой таймаут и фильтрация актуальной
версии страницы. Внешние сервисы в этих тестах подменены.

Реальные вызовы модели и сервисов отдельно подтвердили загрузку URL,
запись пяти векторов, поиск и ответ по источнику, а также GET к API.

## Вывод

Агент получил внешний учебный материал, сохранил его в векторной памяти
и использовал найденные фрагменты для ответа. Отдельный инструмент
получает актуальный ответ открытого API вместо заглушки. Загрузка,
поиск и генерация разделены, а в ответе сохраняется связь с источником.
